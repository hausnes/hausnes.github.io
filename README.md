## Slik oppdaterer du portfolioen

- **Prosjekt:** Alt innhald ligg i `prosjekt.js`. Legg til, fjern eller endre prosjekt der.
- **I søkelyset:** Endre `framheva` øvst i `prosjekt.js` til id-en til prosjektet du vil framheve.
- **Filter:** Filterknappane blir laga automatisk frå `taggar` på kvart prosjekt.
- **Skjermdumpar:** Køyr `sh verktoy/skjermdump.sh` frå rotmappa (krev Firefox). Prosjekt utan bilete får eit generert omslag.
